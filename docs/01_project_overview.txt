 1. 프로젝트 한 줄 요약
────────────────────────────────────────────────────────────────────────────

  "이탈리아 식품 브랜드 Mulino Bianco가 한국 시장에 진출한다고 가정하고,
   EU 기준 ERP 시스템을 한국 식품 법규에 맞게 현지화(Localization)한 뒤,
   그 위에 AI 에이전트를 얹어 구매·공급망·품질 업무를 자동화한
   가상의 ERP 시스템이다."

────────────────────────────────────────────────────────────────────────────
 2. 기획 의도
────────────────────────────────────────────────────────────────────────────

  ● 단순히 기존 브랜드를 따라 만드는 것이 아니라,
    "한국에 들여온다"는 시나리오를 잡아서 신선함과 스토리를 확보

  ● SAP 컨설턴트의 실제 핵심 업무 중 하나가 바로
    "글로벌 ERP 템플릿을 각 나라 법규/관행에 맞게 현지화"하는 작업.
    해당 프로젝트는 그 과정을 직접 설계로 시뮬레이션함.

 5. ERP 데이터 모델 (L0) — 24개 테이블
────────────────────────────────────────────────────────────────────────────

  [공급업체/원자재]
    suppliers               원자재 공급업체
    supplier_certifications 공급업체 인증서 (HACCP/GMP 등, 만료 관리)
    allergens               알레르겐 마스터 (한국 22종)
    raw_materials           원자재
    raw_material_allergens  원자재-알레르겐 매핑

  [구매/입고]  ← SAP MM
    purchase_orders         발주 헤더
    purchase_order_items    발주 상세
    inbound                 입고 내역 (3-Way Match)
    inbound_temperature_logs 입고 운송 온도
    raw_material_lots       원재료 LOT (추적 핵심)

  [창고]  ← SAP WM
    warehouses              창고 (상온/냉장/냉동)
    warehouse_temperature_logs 창고 온도 모니터링
    stock                   완제품 현재 재고

  [생산]  ← SAP PP
    production_records      생산가공기록
    production_ingredients  투입 원재료 추적
    production_lots         생산 LOT (추적 핵심)
    products               완제품

  [수주/출고]  ← SAP SD
    customers               거래처
    orders                  수주 헤더
    order_items             수주 상세
    outbound                출고 내역
    outbound_lots           출고 LOT 추적

  [품질]  ← SAP QM
    recalls                 리콜 관리

  [시스템]
    users                   사용자 (권한 5종: ADMIN/MANAGER/OPERATOR/QC/VIEWER)


────────────────────────────────────────────────────────────────────────────
 6. 핵심 설계 개념
────────────────────────────────────────────────────────────────────────────

  ● 3-Way Match (구매 검증)
    발주(purchase_orders) → 입고(inbound) → 송장 을 연결하여
    "발주한 만큼 실제로 들어왔는지" 검증하는 SAP MM 핵심 개념.

  ● Batch Management (양방향 LOT 추적)
    - 역추적 : 완제품 → 생산LOT → 원재료LOT → 공급업체 (문제 원인 파악)
    - 순추적 : 공급업체 → 원재료LOT → 생산LOT → 출고처 (리콜 범위 파악)
    식품 안전 규정 대응의 핵심.

  ● Governance (거버넌스)
    AI 에이전트가 마음대로 데이터를 바꾸지 못하게,
    모든 액션을 권한(role)에 따라 승인/차단하는 통제 계층.
    → SAP GRC(거버넌스/컴플라이언스) 개념과 대응.


────────────────────────────────────────────────────────────────────────────
 7. AI 에이전트 시나리오 (우선 구현 3종)
────────────────────────────────────────────────────────────────────────────

  [Supply Chain Agent] 공급망
    - 유통기한 30일 이내 원재료 자동 감지 → 우선 사용 권고
    - 재고 소진 예측 → Procurement Agent에 재발주 요청

  [Procurement Agent] 구매
    - 공급업체 인증서 만료 30일 전 감지 → 담당자 알림
    - 납품 지연 감지 → 대체 발주 제안
    - 재발주 요청 수신 → 발주 Draft 생성 → 승인 요청

  [QC Agent] 품질관리
    - 알레르겐 미등록 원자재 입고 감지 → 입고 차단
    - 입고 온도 기준 이탈 감지 → 입고 보류
    - LOT 이상 감지 → 리콜 Draft 생성

  → 이 3개는 각각 실제 데이터(테이블)를 근거로 동작하므로
    "동작하는 데모"를 만들 수 있다.

 8. 기술 스택
────────────────────────────────────────────────────────────────────────────

  DB          : PostgreSQL (DB명: mulino_coreano)
  백엔드      : Spring Boot 3.x + Java 17 + Gradle
  Tool 노출   : Zig CLI `mulino` (백엔드 REST API 클라이언트)
  MCP Server  : 복잡도 관리 필요성 판단 시점까지 도입 보류
  에이전트    : Claude (Claude Code/Cowork) + 역할별 스킬
  프론트      : React (대시보드)
  협업        : GitHub (모노레포)
